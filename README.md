# Deputy Employee Management System



## Description
A command-line application that allows users to view and manage company departments, roles, and employees. Easily navigate through options to retrieve essential information about your organization.

## Installation
To install the application, clone the repository to your local machine using `git clone https://github.com/Bluf00/deputy-employee.git`, navigate into the project directory, install the dependencies by running `npm install`, and then start the application with `npm start`. Follow the on-screen instructions to begin managing employees, roles, and departments.
